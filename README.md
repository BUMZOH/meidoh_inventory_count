# meidoh_inventory_count

メイドー向けの棚卸数量を集計するためのPythonツールです。

`光和工業生産管理.xlsm` の `Data`
シートから対象データを抽出し、品番ごとの数量を集計します。

集計結果はコンソールに表示するとともにクリップボードへコピーします。\
ユーザーは貼り付け先のExcelファイルを開き、`Ctrl + V`
で集計結果を貼り付けます。

## 用途

半年に1回実施する棚卸作業で使用します。

処理対象となるデータは、以下の条件を満たすレコードです。

-   `客先名` が `メイドー`
-   `出荷` が空欄

対象データを `品番` ごとにグループ化し、`数量` を合計します。

## 処理の流れ

1.  プログラムを起動する
2.  `光和工業生産管理.xlsm`
    がプログラムと同じフォルダにあることを確認する
3.  Enterキーを押す
4.  `Data` シートを読み込む
5.  `客先名 = メイドー` のデータを抽出する
6.  `出荷` が空欄のデータを抽出する
7.  `品番` ごとにグループ化する
8.  `数量` を合計する
9.  `品番` の昇順で並べ替える
10. 集計結果をコンソールに表示する
11. `品番` と `数量` をクリップボードへコピーする
12. 貼り付け先のExcelで `Ctrl + V` して結果を貼り付ける

## 必要なファイル

以下のように、PythonファイルとExcelファイルを同じフォルダに配置します。

``` text
meidoh_inventory_count/
├─ meidoh_inventory_count.py
└─ 光和工業生産管理.xlsm
```

Excelファイルが存在しない場合は、`FileNotFoundError`
が発生して処理を終了します。

## Excelデータ

読み込み対象のシート名は `Data` です。

処理では以下の列を使用します。

  列名     用途
  -------- ---------------------------
  客先名   `メイドー` のデータを抽出
  出荷     空欄のデータを抽出
  品番     グループ化および並べ替え
  数量     品番ごとの数量を集計

## 集計条件

抽出条件は以下です。

``` text
客先名 = "メイドー"
AND
出荷 = 空欄
```

抽出したデータを品番ごとにまとめ、数量を合計します。結果は品番の昇順で並べ替えます。

## クリップボードへのコピー

集計結果のうち、`品番` と `数量` の2列をクリップボードへコピーします。

実際にクリップボードへコピーされるデータにはヘッダーを含めません。

``` text
ABC001    100
ABC002    250
ABC003     80
```

貼り付け先のExcelで開始セルを選択して `Ctrl + V`
するだけで、品番と数量を2列に貼り付けることができます。

Pythonから貼り付け先のExcelファイルを直接編集することはありません。

## 対象データが存在しない場合

フィルタ後のデータが0件だった場合は、

``` text
集計対象のデータがありません。
```

と表示して処理を終了します。

空の集計結果をクリップボードへコピーすることはありません。

## 必要なPythonパッケージ

-   pandas
-   openpyxl

インストールされていない場合は、以下のコマンドでインストールします。

``` bash
pip install pandas openpyxl
```

## 実行方法

``` bash
python meidoh_inventory_count.py
```

起動すると、以下のようなメッセージが表示されます。

``` text
============================================================
メイドー 棚卸数量集計
============================================================

集計対象のExcelファイルがフォルダ内にあることを確認してください。
対象ファイル: 光和工業生産管理.xlsm

確認できたら Enter キーを押してください...
```

対象ファイルを確認してEnterキーを押すと集計を開始します。

集計完了後、結果がコンソールに表示され、クリップボードへコピーされます。

``` text
集計結果をクリップボードにコピーしました。
貼り付け先のExcelで Ctrl + V してください。
```

## 設計方針

半年に1回実施する棚卸作業を簡単にするため、処理をできるだけシンプルにしています。

``` text
Excel読込
    ↓
フィルタ
    ↓
品番別集計
    ↓
並べ替え
    ↓
コンソール表示
    ↓
クリップボードへコピー
```

貼り付け先のExcelファイルやセル位置をプログラムから操作せず、最終的な貼り付け作業はユーザーが行います。

これにより、貼り付け先Excelのレイアウト変更などの影響を受けにくい、シンプルな構成としています。
